# 📝 Text Summarizer Web App (Hugging Face T5 + FastAPI)

A full-stack NLP web application that generates concise summaries of dialogue and text using a Hugging Face T5 Transformer model and a FastAPI backend.

## 🚀 Tech Stack
* **Machine Learning:** Hugging Face `transformers` (`T5ForConditionalGeneration`, `T5Tokenizer`), PyTorch
* **Backend API:** FastAPI, Uvicorn, Jinja2
* **Frontend UI:** HTML5, CSS3, JavaScript (Fetch API)
